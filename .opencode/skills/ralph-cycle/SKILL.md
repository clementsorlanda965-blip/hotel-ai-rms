## 做什么
Ralph循环：自动化软件开发的完整循环。

## 流程
1. **需求** → 拆解为可执行任务列表
   ⚠ **用户确认**：展示任务列表给用户，确认后再进入开发
2. **开发** → 逐任务编码实现
3. **测试** → 运行测试验证
   - 失败 → 进入修复步骤
   - 通过 → 进入提交步骤
4. **修复** → 失败则自动修复，然后回到测试步骤重新验证
5. **提交** → 通过后提交代码
   ⚠ **用户确认**：展示改动摘要给用户，确认后再提交
6. **循环** → 下一任务，直到全部完成

## 异常处理
| 场景 | 处理方式 |
|------|----------|
| 测试反复失败超过3次 | 暂停循环，询问用户：继续修复 / 跳过该任务 / 终止整个流程 |
| 用户在检查点拒绝 | 记录用户反馈原因，终止当前任务，跳到下一个 |
| 前置任务未完成 | 标记当前任务为"阻塞"，等待前置任务完成后自动解除 |
| Git 提交失败（冲突） | 提示冲突文件路径，生成补丁文件，等待用户手动解决 |

## 适用场景
- 多页面网站开发
- 批量功能实现
- 自动化测试修复
