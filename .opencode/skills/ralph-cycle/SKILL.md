## 做什么
Ralph循环：自动化软件开发的完整循环。

## 流程
1. **需求** → 拆解为可执行任务列表
   ⚠ **用户确认**：展示任务列表给用户，确认后再进入开发
2. **开发** → 逐任务编码实现
3. **测试** → 运行测试验证
   - 失败 → 进入修复步骤
   - 通过 → 进入提交步骤
4. **修复** → 失败则自动修复，然后回到测试步骤重新验证
5. **提交** → 通过后提交代码
   ⚠ **用户确认**：展示改动摘要给用户，确认后再提交
6. **循环** → 下一任务，直到全部完成

## 适用场景
- 多页面网站开发
- 批量功能实现
- 自动化测试修复
