## 做什么
检测并消除中文文本中的AI生成痕迹，使文案读起来像人类自然书写。适用于短视频解说脚本、口播稿、公众号文章等场景。

## 强制规则
所有输出必须是中文。只改表达方式，不改事实信息。保留原文语气。

## AI写作模式检测（24种）

### 一、内容模式（5种）
| 模式 | 特征 | 示例→改写 |
|------|------|-----------|
| 过度总结 | 每段末尾必有总结句 | "综上所述"→直接去掉 |
| 对称结构 | 三/四句排比收尾 | "无论是...还是..."→只留一句 |
| 强行升华 | 结尾拔高立意 | "共创美好未来"→替换为具体行动 |
| 过度说明 | 每个概念附带解释 | 根据上下文决定 |
| 万能过渡 | 固定衔接句式 | "值得注意的是"→直接去掉 |

### 二、语言语法模式（7种）
| 模式 | 改写方式 |
|------|---------|
| 复杂长句(>30字) | 拆成2-3个短句，每句≤20字 |
| 过度被动("被""受到") | 改为主动语态 |
| 滥用副词("非常""极其") | 删除80%程度副词 |
| 书面语("因此""然而") | 改为"所以""但" |
| 完美衔接 | 允许跳跃，去掉部分衔接词 |
| 固定搭配("在...方面") | 换为更直接表达 |
| 数字滥用 | "高达99.9%"→"绝大多数" |

### 三、风格模式（7种）
| 模式 | 改写方式 |
|------|---------|
| 模板化开头("在当今") | 直接切入主题 |
| 列表癖("第一/第二") | 改为自然段落 |
| 机器人节奏 | 混合长短句+破折号/冒号 |
| 缺口语词 | 加入"吧""嘛""呢""啊" |
| 缺人称 | 补充"我""你""我们" |
| 万能用词("重要""核心") | 替换为具体描述 |
| 缺节奏变化 | 混合陈述/疑问/感叹句式 |

### 四、交流模式（5种）
| 模式 | 改写方式 |
|------|---------|
| 单向灌输 | 加入反问"你知道吗？" |
| 过度礼貌("请""感谢") | 根据场景精简 |
| 无情感标记 | 适当加入情感词 |
| 完美收尾 | 允许开放式结尾 |
| 信息过载 | 拆为多段，每段1个核心点 |

## 工作流程
1. 输入分析：扫描全文标记AI模式命中位置
2. 逐项消除：内容模式→语言语法→风格→交流
3. 输出对比：展示修改前后对比，用户确认

## 边界条件
| 场景 | 处理方式 |
|------|---------|
| 输入<50字 | 无需处理，直接返回 |
| 专业文档 | 保持术语准确性 |
| 诗歌/修辞排比 | 保留故意设计的修辞 |
