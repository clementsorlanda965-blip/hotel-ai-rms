## 强制规则
**所有文字输出必须是中文。** 你说需求，出文档。

## 工作流程

### Step 1: 解析需求 → 匹配文档类型
读取用户输入，自动匹配文档类型：

```python
doc_types = {
    "SOP":         ["标准操作", "流程", "操作规范", "sop"],
    "会议纪要":     ["开会", "会议", "记录", "纪要"],
    "合同协议":     ["合同", "协议", "签约"],
    "培训手册":     ["培训", "新人", "入职", "带教"],
    "客诉记录":     ["投诉", "客诉", "纠纷", "差评"],
}
for doc_type, keywords in doc_types.items():
    if any(kw in user_input for kw in keywords):
        matched_type = doc_type; break
```

未匹配时主动提问引导用户从以上 5 类中选择。

### Step 2: 按模板生成文档

**SOP 模板**
```md
# [酒店名称] - [流程名称] 标准操作流程
| 步骤 | 岗位 | 操作内容 | 工具/材料 | 质量标准 | 备注 |
|------|------|----------|-----------|----------|------|
| 1 | 前台 | 核实预订信息：询问姓名+预订号 | PMS 系统 | 30秒内完成接待 | — |
| 2 | 前台 | 办理入住手续 | 身份证读卡器 | 信息录入准确率100% | 原件归还 |
```

**会议纪要模板**
```md
# [酒店名称] - 会议纪要
- **时间**: YYYY-MM-DD HH:mm | **地点**: [会议室/线上]
- **主持人**: [姓名] | **参会人**: [姓名1、姓名2]
- **议题**:
  1. [议题1] → 结论：[...] → 负责人：[...] → 截止：YYYY-MM-DD
  2. [议题2] → ...
- **下次会议**: YYYY-MM-DD
```

**合同协议模板**
```md
# [合同名称]
**甲方**: [酒店名称]（营业执照号：[...]）
**乙方**: [合作方名称]（营业执照号：[...]）

## 第一条 合作内容
[描述合作范围、服务内容]

## 第二条 合同期限
自 YYYY-MM-DD 至 YYYY-MM-DD

## 第三条 费用与支付
[金额、支付方式、发票条款]

## 第四条 双方权利义务
[甲方义务...] / [乙方义务...]

## 第五条 违约责任
[违约金比例、赔偿范围] ⚠️ 风险点：违约金不超过实际损失的30%

## 第六条 争议解决
[仲裁/诉讼地]

**甲方签章**:           **乙方签章**:
日期:                  日期:
```

**培训手册模板**
```md
# [酒店名称] - [岗位] 培训手册
## 培训目标
[培训结束后学员能掌握的 X 项核心技能]
## 培训模块
### 模块一：[模块名称]
- 核心知识点：[3-5个关键概念]
- 实操练习：[具体操作步骤]
- 考核标准：[量化指标，如"15分钟内完成"]
- 预计时长：XX 分钟
```

**客诉记录模板**
```md
# 客诉处理记录单
- **投诉编号**: CS-YYYYMMDD-XXX
- **投诉人**: [姓名/房号] | **投诉时间**: YYYY-MM-DD HH:mm
- **投诉渠道**: 前台 / 电话 / 在线平台 / 社交媒体
- **投诉类型**: 客房 / 餐饮 / 服务态度 / 设施 / 其他
- **投诉内容**: [客观描述，不添加主观判断]
- **处理人**: [姓名]
- **处理过程**: HH:mm — 动作描述（按时间线）
- **处理结果**: 已解决 / 跟进中 / 升级处理
- **客户反馈**: 满意 / 一般 / 不满意
- **改进措施**: [具体可执行方案]
```

### Step 3: 填充内容与润色
- 内容具体可执行，避免空泛描述
- SOP 每步骤有可衡量的质量标准（时间/数量/准确率）
- 合同条款标注关键风险点（用 ⚠️ 标记）
- 客诉记录必须输出可执行的改进措施

### Step 4: 交付文件
保存为 Markdown 到 `E:\工作AI\酒店管理\`，文件名格式：`[类型]_[酒店名称]_[日期].md`

## 文档质量准则

| 维度 | 要求 | 反例 |
|------|------|------|
| 具体性 | 可量化、可执行的操作描述 | "做好服务"、"加强管理" |
| 完整性 | 包含模板中所有必要字段 | SOP缺少质量标准列 |
| 行业规范 | 术语符合酒店业习惯 | 使用非标准岗位名称 |
| 可追溯 | 每项任务有负责人和时限 | "尽快完成"、"相关人员" |

## 边界条件

| 场景 | 处理方式 |
|------|----------|
| 用户未提供酒店名称 | 使用 `[酒店名称]` 占位，标注用户自行替换 |
| 多项目混合需求 | 主动提问拆分顺序，逐个生成不混为一个文件 |
| 批量生成同类型文档 | 使用模板+变量替换，一次性全部生成 |
| 双语版本需求 | 先生成中文，再逐条翻译为英文对照版 |
| 历史文档修订 | 读取原文件，用「增：」「删：」「改：」标注变更 |
