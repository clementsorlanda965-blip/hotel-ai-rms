## 做什么
优化代码但不改变行为。精简冗余、提高可读性、降低复杂度。
## 规则
- 不改功能，只改写法
- 删除无用变量、死代码、重复逻辑
- 合并重复代码块
- 改善命名
- 减少嵌套层级
- 不添加注释（除非用户要求）
## 工作流程
1. **读取分析** — 用 Read 读取目标文件，识别以下问题点：
   - 未使用变量、死代码、重复代码块
   - 超过3层嵌套的 if/for/while
   - 模糊命名
2. **分步重构** — 用 Edit 逐个修改，每改一处即确认不改变功能逻辑
   - 先删无用代码，再合并重复，最后改善命名和减少嵌套
3. **验证** — 用 Bash 运行测试或编译命令，确保输出与修改前一致
   - 若无自动化测试，至少做一次肉眼复核
