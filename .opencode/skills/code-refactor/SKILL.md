## 做什么
精简冗余、提高可读性、降低复杂度，不改行为。
## 规则
不改功能 | 删无用变量死代码 | 合并重复块 | 改善命名 | 减少嵌套 | 不加注释
## 工作流程
1. **读取分析** — Read 文件，标记：未用变量/死代码/重复块/超3层嵌套/模糊命名
2. **分步重构** — Edit 逐项改：删无用→合并重复→改善命名→减少嵌套
3. **验证** — Bash 运行测试；无测试→肉眼比对；失败→回滚Edit
4. **交付** — 输出修改摘要（改了哪些/为什么改）

## 检查点
- 重构前→确认备份或git stash
- 批量改多个文件→每文件改完确认

## 边界情况
- 文件不存在→提示路径错误，停止
- 文件无需修改→说明"无需重构"
- 重构后编译失败→回滚到上一个版本
