## 强制规则
所有文字输出必须是中文。表头、数据标签、图表标注全部中文。输出为 .xlsx 格式。

## 做什么
根据用户提供的酒店数据（或默认模拟数据），自动生成专业酒店经营分析Excel报表。

## 工作流程

1. **理解需求** — 从用户输入识别：报表类型、周期、关注指标
2. **展示方案给用户确认** — 明确报表类型、时间范围、对比基准，用户同意后继续
3. **数据准备** — 使用用户提供的原始数据；若无可用数据，生成符合酒店行业规律的模拟数据
4. **生成Excel报表** — 按输出格式规范，用Python生成含公式/图表/条件格式的.xlsx
5. **展示结果给用户确认** — 打开文件供预览，询问是否需要修改（周期/指标/对比对象）
6. **迭代调整** — 如用户提出修改，返回到步骤3或4，最多3轮调整

## 报表类型

| 类型 | 触发词 | 包含内容 |
|------|--------|----------|
| 日经营快报 | 每日报表/日报/今日数据 | RevPAR/ADR/OCC/收入/GOP率 |
| 周经营分析 | 周报/本周/一周数据 | 7天趋势+周汇总+同比环比 |
| 月度经营报告 | 月报/月度/本月数据 | 30天趋势+部门分析+预算对比 |
| 渠道分析 | 渠道/OTA/佣金 | 各渠道间夜/ADR/佣金/占比 |
| GOP分析 | GOP/利润/损益 | 收入-部门费用-未分配=GOP |
| 预算执行 | 预算/执行率/差异 | 实际vs预算vs去年同期 |

## 输出格式

- **Excel文件(.xlsx)** — 含公式、图表(SVG)、条件格式
- 颜色规范：收入=蓝色、费用=红色、达标=绿色、警告=橙色
- 自动计算：RevPAR = OCC × ADR、GOP率 = GOP ÷ 收入
- 图表：折线图(趋势)、柱状图(对比)、饼图(占比)
- 条件格式：超预算标红、达标标绿

## 使用示例

"生成本月酒店经营分析报表" → 输出30天OCC/ADR/RevPAR趋势 + 部门收入构成 + GOP计算
"分析各OTA渠道表现" → 输出渠道间夜对比 + 佣金率 + 直销占比建议
"做一份周报给总经理" → 输出7天核心KPI + 本周亮点 + 预警项

## 酒店行业数据标准

| 指标 | 优秀 | 达标 | 需改善 |
|------|------|------|--------|
| OCC | >80% | 65-80% | <65% |
| RevPAR | >¥500 | ¥350-500 | <¥350 |
| GOP率 | >40% | 32-40% | <32% |
| 人房比 | 0.8-1.0 | 1.0-1.2 | >1.2 |

## 异常处理
- 无原始数据→自动生成模拟数据，标注"仅供参考"
- Python缺openpyxl→自动安装：`pip install openpyxl xlsxwriter`
- 数据格式不符→智能解析，失败则提示按模板重试
- 图表生成失败→降级为数值表格
- 文件被占用→追加时间戳重命名
- 需求模糊→默认月度报告，提示可调整
