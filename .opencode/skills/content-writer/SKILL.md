## 强制规则
所有文字输出必须是中文。脚本、标题、封面文案全部中文。输出到 `outputs/` 或直接返回文本。

## 做什么
影视解说短视频的文案全链路优化——从原始素材/草稿出发，输出精炼的解说脚本、抓人标题和封面文案。贴合抖音/B站/小红书的短视频节奏。

## 检查点

### Step 0: 模式确认
向用户展示 4 种写作模式（脚本润色/标题生成/封面文案/口播改写）及各自输入要求，用户确认模式后再执行。

### Step 2: 输出预览确认
生成结果后展示给用户预览，询问是否需要修改或调整风格再输出。

### Step 3: 写入确认
如需要写入 script.json，先向用户展示写入内容摘要，确认后再写文件。

## 写作模式

| 模式 | 输入 | 输出 | 适用场景 |
|------|------|------|----------|
| **脚本润色** | 原始解说稿 | 优化后口播脚本 | 短视频配音文本 |
| **标题生成** | 视频内容摘要 | 5个爆款标题候选 | 发布前选标题 |
| **封面文案** | 标题+核心看点 | 封面大字+副标题 | 封面配文 |
| **口播改写** | 书面文稿 | 口语化口播稿 | 播客/AI配音 |

## 工作流

总流程：`原始素材 → 检查点Step0模式确认 → 按模式处理 → 检查点Step2预览确认 → 检查点Step3写入确认 → outputs/script.json`

### 模式一：脚本润色

| 子步骤 | 输入 | 操作 | 输出 |
|--------|------|------|------|
| 1a 核心提取 | 原始解说稿 | 提取核心冲突/人物/事件 | 冲突摘要 |
| 1b 口播重写 | 冲突摘要 | 每句≤15字，删书面语(因此/于是/然而→所以/结果/但)，保留史实 | 口播草稿 |
| 1c 分镜断句 | 口播草稿 | 每镜头一个钩子句(悬念/冲突/反转)，标注 emotion 字段 | 分镜脚本 |
| 1d 去AI味(可选) | 分镜脚本 | 调用 humanizer-zh 消除AI痕迹，混合长短句+口语词+人称+反问 | 自然人声脚本 |

### 模式二：标题生成

| 风格 | 模板 | 示例 |
|------|------|------|
| 悬疑问 | [人物]为什么[行为]？真相令人[情绪] | 嘉靖为什么20年不上朝？真相令人毛骨悚然 |
| 冲突型 | [人物A]VS[人物B]：[事件]背后的[博弈] | 严嵩VS徐阶：大明最精彩的权力游戏 |
| 数据型 | [数字]分钟看懂[事件]：[结果] | 3分钟看懂改稻为桑：一场国策如何毁掉半个江南 |
| 情绪型 | [事件]那一刻，[人物]终于[情绪] | 血溅午门那一刻，海瑞终于明白了一切 |

### 模式三：封面文案

| 元素 | 限制 | 内容 |
|------|------|------|
| 主标题 | ≤8字，大字居中 | 核心冲突/悬念 |
| 副标题 | ≤15字，小字下方 | 一句话剧情概括 |

### 与 video-factory 集成

工作流最后一步将优化后脚本写入 script.json，供 video-factory（合成引擎）使用：
如需去AI味，在写入前先调用 humanizer-zh 处理旁白文本。
完整管线：`content-writer → [humanizer-zh] → image-generator → audio-tts → speech-recognition → video-factory`
```json
[
  {
    "id": 1,
    "narration": "大明王朝，中国历史上最后一个汉人封建王朝。",
    "subtitle": "最后一个汉人王朝",
    "visual": "imperial palace at dusk, cinematic lighting, 35mm lens",
    "emotion": "hook"
  }
]
```
路径：`outputs/script.json`

## 写作规范

| 维度 | 规范 |
|------|------|
| 旁白字数/镜头 | 10-20字 |
| 字幕字数 | ≤8字 |
| 总镜头数 | 7-12镜/分钟 |
| 情绪节奏 | hook(开头) → 共鸣(铺垫) → 冲突(高潮) → 亢奋(收尾) |
| 钩子位置 | 前3秒必须抛出悬念 |

## 边界条件处理

| # | 场景 | 处理方式 |
|---|------|----------|
| 1 | 输入文本为空 | 提示"请提供原始文案/素材"，不继续生成 |
| 2 | 输入为图片或链接 | 提示"请先提取图片/链接中的文字内容" |
| 3 | 生成标题时主题过于模糊 | 追问具体人物、事件、冲突点，获取足够信息后再生成 |
| 4 | script.json 写入失败（文件被占用/只读） | 重试 3 次；若仍失败，提示手动关闭文件或选择其他路径 |
| 5 | 用户对输出不满意 | 提供迭代修改机制：每次反馈后重新优化，最多 3 轮 |
| 6 | 输出的标题/文案长度超限 | 自动截断到限制长度，并提示用户已截断 |
| 7 | 多镜头脚本中某个镜头字数 > 25 字 | 自动拆分为两个镜头，并标注拆分位置 |
| 8 | 用户要求非中文输出 | 提示"所有输出必须是中文" |

## 注意事项
1. 影视解说需标注素材来源，避免版权争议
2. 保持史实准确性，不为了爆款扭曲历史
3. 优化后脚本自动写回 script.json，供后续环节使用
4. 标题建议每次生成5个，供人工挑选
