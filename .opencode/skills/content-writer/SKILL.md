## 强制规则
所有文字输出必须是中文。脚本、标题、封面文案全部中文。输出到 `outputs/` 或直接返回文本。

## 做什么
影视解说短视频的文案全链路优化——从原始素材/草稿出发，输出精炼的解说脚本、抓人标题和封面文案。贴合抖音/B站/小红书的短视频节奏。

## 检查点

### Step 0: 模式确认
向用户展示 4 种写作模式（脚本润色/标题生成/封面文案/口播改写）及各自输入要求，用户确认模式后再执行。

### Step 2: 输出预览确认
生成结果后展示给用户预览，询问是否需要修改或调整风格再输出。

### Step 3: 写入确认
如需要写入 script.json，先向用户展示写入内容摘要，确认后再写文件。

## 写作模式

| 模式 | 输入 | 输出 | 适用场景 |
|------|------|------|----------|
| **脚本润色** | 原始解说稿 | 优化后口播脚本 | 短视频配音文本 |
| **标题生成** | 视频内容摘要 | 5个爆款标题候选 | 发布前选标题 |
| **封面文案** | 标题+核心看点 | 封面大字+副标题 | 封面配文 |
| **口播改写** | 书面文稿 | 口语化口播稿 | 播客/AI配音 |

## 工作流

### 1. 脚本润色
```
原始文稿 → 提取核心冲突 → 重写为口播语言 → 分镜头断句 → 输出
```

润色原则：
- 每句≤15字，适合配音节奏
- 删除书面语（"因此""于是""然而"→"所以""结果""但"）
- 保留史实精确性，只优化表达
- 每镜头设置钩子句（悬念/冲突/反转）

### 2. 标题生成器

| 风格 | 模板 | 示例 |
|------|------|------|
| 悬疑问 | [人物]为什么[行为]？真相令人[情绪] | 嘉靖为什么20年不上朝？真相令人毛骨悚然 |
| 冲突型 | [人物A]VS[人物B]：[事件]背后的[博弈] | 严嵩VS徐阶：大明最精彩的权力游戏 |
| 数据型 | [数字]分钟看懂[事件]：[结果] | 3分钟看懂改稻为桑：一场国策如何毁掉半个江南 |
| 情绪型 | [事件]那一刻，[人物]终于[情绪] | 血溅午门那一刻，海瑞终于明白了一切 |

### 3. 封面文案
```
主标题（≤8字，大字居中）：[核心冲突/悬念]
副标题（≤15字，小字下方）：[一句话剧情概括]
```

### 4. 与 video-factory 集成
```
content-writer → 优化后脚本 → outputs/script.json → video-factory → 完整视频
```

脚本优化后直接写入 video-factory 的标准 script.json 格式：
```json
[
  {
    "id": 1,
    "narration": "大明王朝，中国历史上最后一个汉人封建王朝。",
    "subtitle": "最后一个汉人王朝",
    "visual": "imperial palace at dusk, cinematic lighting, 35mm lens",
    "emotion": "hook"
  }
]
```

## 写作规范

| 维度 | 规范 |
|------|------|
| 旁白字数/镜头 | 10-20字 |
| 字幕字数 | ≤8字 |
| 总镜头数 | 7-12镜/分钟 |
| 情绪节奏 | hook(开头) → 共鸣(铺垫) → 冲突(高潮) → 亢奋(收尾) |
| 钩子位置 | 前3秒必须抛出悬念 |

## 注意事项
1. 影视解说需标注素材来源，避免版权争议
2. 保持史实准确性，不为了爆款扭曲历史
3. 优化后脚本自动写回 script.json，供后续环节使用
4. 标题建议每次生成5个，供人工挑选
